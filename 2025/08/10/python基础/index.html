python 基础

Python 是一个高层次的结合了解释性、编译性、互动性和面向对象的脚本语言。

Python 的设计具有很强的可读性，相比其他语言经常使用英文关键字，其他语言的一些标点符号，它具有比其他语言更有特色语法结构。

  • Python 是一种解释型语言：  这意味着开发过程中没有了编译这个环节。类似于 PHP 和 Perl 语言。
  • Python 是交互式语言：  这意味着，您可以在一个 Python 提示符  >>>  后直接执行代码。
  • Python 是面向对象语言:  这意味着 Python 支持面向对象的风格或代码封装在对象的编程技术。
  • Python 是初学者的语言： Python 对初级程序员而言，是一种伟大的语言，它支持广泛的应用程序开发，从简单的文字处理到 WWW 浏览器再到游戏。

2 数据类型

2.1 变量与常量

2.1.1 变量

  • ​​ 定义 ​​：动态存储数据的命名容器，值可修改
  • 命名规则 ​​：
    • 由字母/数字/下划线组成，​​ 禁止数字开头 ​​（如  1_name非法）
    • 区分大小写（age与  Age不同）
    • 避免使用关键字（如  for/if）

2.1.2 常量

  • 定义 ​​：程序运行中 ​​不可修改 的固定值
  • ​​Python 实现 ​​：
    • ​​ 约定俗成 ​​：全大写命名（如  PI = 3.14159）
    • ​​ 强制不变 ​​：通过元组或枚举实现

2.2 数据类型

  • int(): 将数字转换成整数
  • float(): 将数字转换成浮点数
  • str(): 将数字转换成字符串
  • list(): 将数字转换成列表
  • tuple(): 将数字转换成元组
  • dict(): 将数字转换成字典
  • set()：将数字转换成集合
  • bool()：将数字转换成布尔值
  • ord()：将字符转换成 ASCII 码
  • chr()：将 ASCII 码转换成字符

2.2.1 基本数据类型

  • 数值类型 ​​：
    • ​​ 整型（int）​​：无大小限制（10**100合法）
    • ​​ 浮点型（float）​​：注意精度问题（0.1 + 0.2 = 0.30000000000000004）
    • ​​ 复数（complex）​​：z = 3 + 4j，z.real获取实部
  • ​​ 布尔型（bool）​​：
    • 仅  True/False，继承自整型（True == 1, False == 0）
    • 逻辑运算：and/or/not
  • ​​ 字符串（str）​​：
    • 不可变序列，支持单/双/三引号定义（三引号保留换行格式）
2.2.1.1 数值类型
2.2.1.1.1 整型(int)
  • 无大小限制（支持超大整数，如  10**100）
  • 支持二进制（0b1010）、八进制（0o12）、十六进制（0xA）表示，输出自动转为十进制
  • 可用下划线分隔大数（1_000_000等价于  1000000）
2.2.1.1.2 ​​ 浮点型(float)
  • 含小数点的数（如  3.14）或科学计数法（3.14e-2 = 0.0314）
  • ​​ 精度问题 ​​：二进制浮点数无法精确表示所有十进制小数（如  0.1 + 0.2 = 0.30000000000000004）
  • 浮点数比较 ​​：
    • 避免直接比较：0.1 + 0.2 == 0.3返回  False
    • 使用误差范围：abs(0.1 + 0.2 - 0.3) < 1e-10
2.2.1.1.3 ​​ 复数（complex）​​
  • 直接赋值：z = 3 + 4j
  • 构造函数：z = complex(3, 4)（实部 3，虚部 4）
2.2.1.2 布尔类型
2.2.1.2.1 bool
  • 仅两个值：True（真）和  False（假），首字母必须大写
  • 继承自整型：True == 1，False == 0，可直接参与算术运算
2.2.1.2.2 逻辑运算
  • and（与）：全真为真（True and False → False）
  • or（或）：一真即真（True or False → True）
  • not（非）：取反（not True → False）
2.2.1.2.3 隐式布尔
  • 空值/零值自动转为  False
2.2.1.3 字符串
  • 不可变 ​​：创建后不能修改（如  s = "abc"; s[0] = "d"会报错）
  • ​​ 定义方式 ​​：
    • 单/双引号：s1 = 'hello', s2 = "world"
    • 三引号：保留多行格式（如文档字符串）
  • ​​ 转义字符 ​​：\n（换行）、\t（制表符）、\\（反斜杠）
  • ​​ 原始字符串 ​​（前缀  r）：忽略转义，直接输出原始内容
2.2.1.3.1 eval() 函数
  • 内置函数
  • eval(): 将字符串转换成代码并执行
  • 经常与input()函数一起使用
  • 去掉一对引号

2.2.2 组合数据类型

  • ​​ 序列类型 ​​：
    • ​​ 列表（list）​​：可变有序序列，[1, "a", True]
    • ​​ 元组（tuple）​​：不可变有序序列，(10, "data", None)
  • ​​ 集合类型 ​​：
    • ​​ 集合（set）​​：无序不重复，{1, 2, 3}
  • ​​ 映射类型 ​​：
    • ​​ 字典（dict）​​：键值对映射，键必须不可变（如字符串/数字）
2.2.2.1 列表
  • ​​ 可变有序序列 ​​，元素类型可混合（如  [1, "a", True]）
  • 支持动态增删改，内存空间动态分配
2.2.2.2 元组
  • ​​ 不可变有序序列 ​​（创建后不能修改），如  (10, "data", None)
  • 轻量级，性能优于列表，适合存储常量数
2.2.2.3 集合
  • ​​ 无序不重复 ​​ 元素集合（如  {1, 2, 3}）
  • 元素必须可哈希（不可变类型如 int/str/tuple）
2.2.2.4 字典
  • 键值对映射 ​​（键必须不可变：str/int/tuple，值任意）
  • 无序（Python 3.7+后按插入序保留）
  • 常用方法
  • 字典推导
特性 ​​ 列表(list) 元组(tuple) 集合(set) 字典(dict)
​​ 可变性 ​​ ✔️ 可变 ❌ 不可变 ✔️ 可变 ✔️ 可变
​​ 有序性 ​​ ✔️ 有序 ✔️ 有序 ❌ 无序 ✔️ 插入序
​​ 元素重复 ​​ 允许重复 允许重复 自动去重 键唯一，值可重复
​​ 查找效率 ​​ O(n)（线性搜索） O(n) O(1)（哈希表） O(1)（按键查找）
​​ 典型应用 ​​ 动态数据集合 常量数据存储 去重/集合运算 键值映射关系

4 函数

4.1 参数基础

  • 位置参数需在关键字参数前（func(10, divisor=2)合法；func(dividend=10, 2)非法）
  • 强制顺序 ​​：位置参数 → *args → 默认参数 → **kwargs
  • 位置参数
  • 关键字参数
  • 默认参数

4.1.1 动态参数

  • 动态位置参数：接受任意数量的位置参数
  • 动态关键字参数: 接受任意数量关键字参数，打包为字典
  • 将序列/字典解包为位置/关键字参数

4.2 参数传递规则

  • ​ 核心规则 ​​：Python 中所有参数传递均为 ​​ 对象引用传递 ​​（非值传递或引用传递）
  • ​​ 强制顺序 ​​：位置参数 → *args → 默认参数 → **kwargs
  • ​ 不可变对象 ​​（int/str/tuple）：函数内修改会创建新对象，不影响原值
  • ​​ 可变对象 ​​（list/dict/set）：函数内修改直接影响原对象
  • ​ 函数接收的是原对象内存地址，无额外拷贝开销
  • ​ 安全实践 ​​：若需隔离外部数据，显式拷贝

4.3.3 闭包

  • 函数作为返回值
4.3.3.1 工厂函数
  • ​​ 核心思想 ​​：
    工厂函数是 ​​ 返回函数或对象的函数 ​​（而非直接调用函数），其作用类似于工厂生产线：输入参数 → 生产特定“产品”（函数/对象）
  • ​​ 与闭包的关系 ​​：
    工厂函数通常基于闭包实现，通过外层函数保存配置参数，内层函数动态应用这些参数

5 re 模块

re模块是 ​​Python 标准库中用于处理正则表达式（Regular Expressions）的内置模块 ​​，提供字符串匹配、搜索、替换、分割等高级文本处理功能。它支持 Perl 风格的正则语法，无需额外安装，通过  import re即可调用

​​ 函数 ​​ ​​ 作用 ​​ ​​ 示例 ​​
re.match() 从字符串 ​​ 起始位置 ​​ 匹配模式，失败返回  None re.match(r'Hello', 'Hello World')→ 匹配成功
re.search() ​​ 全局搜索 ​​ 第一个匹配项 re.search(r'World', 'Hello World')→ 找到  'World'
re.findall() 返回 ​​ 所有匹配子串 ​​ 的列表 re.findall(r'\d+', '123abc456')→ ['123', '456']
re.sub() ​​ 替换 ​​ 匹配项 re.sub(r'\d', '*', 'a1b2')→ 'a*b*'
re.split() ​​ 按模式分割 ​​ 字符串 re.split(r'\s+', 'a b c')→ ['a', 'b', 'c']
re.compile() ​​ 预编译 ​​ 正则表达式，提升重复使用性能 pat = re.compile(r'\d+'); pat.findall('123abc')

5.1 正则表达式

5.1.1 元字符

元字符 ​​ ​​ 作用 ​​ ​​ 示例 ​​ ​​ 匹配结果 ​​ ​​ 反义字符 ​​
. 匹配除换行符（\n）外的 ​​ 任意单个字符 ​​ a.b "aab"、"a&b"（不匹配"a\nb"） -
\d 匹配 ​​ 任意数字 ​​（等价于[0-9]） \d\d "42"（两位数字） \D（非数字）
\w 匹配 ​​ 字母、数字、下划线 ​​（等价于[a-zA-Z0-9_]） \w\w "a1"、"Z_" \W（如"@#"）
\s 匹配 ​​ 空白符 ​​（空格、制表符\t、换行符\n等） a\sb "a b" \S（非空白，如"a"）
^ 匹配 ​​ 行首位置 ​​ ^abc "abcdef"（开头为abc） -
$ 匹配 ​​ 行尾位置 ​​ xyz$ "endxyz"（结尾为xyz） -
\b 匹配 ​​ 单词边界 ​​（单词首尾） \bcat\b "The cat"（不匹配"category"）
\B 匹配 ​​ 非单词边界 ​​ \Bcat\B "scatter"（cat不在边界）
5.1.1.1 限定符
​​ 限定符 ​​ ​​ 作用 ​​ ​​ 贪婪模式示例 ​​ ​​ 懒惰模式 ​​ ​​ 示例结果 ​​
* 匹配 ​​0 次或多次 ​​ a* *? ""（空）、"aaa"
+ 匹配 ​​1 次或多次 ​​ a+ +? "a"、"aa"（不匹配空）
? 匹配 ​​0 次或 1 次 ​​ ab?c ?? "ac"、"abc"
{n} 匹配 ​​ 恰好 n 次 ​​ a{3} {n}? "aaa"（不匹配"aa"）
{n,} 匹配 ​​ 至少 n 次 ​​ a{2,} {n,}? "aa"、"aaaa"
{n,m} 匹配 ​​n 到 m 次 ​​ a{2,4} {n,m}? "aa"、"aaa"（不匹配"a"）
5.1.1.1.1 贪婪模式 and 非贪婪模式
  • 贪婪模式 ​​：引擎会一直匹配直到无法匹配为止，然后逐步回溯
  • 非贪婪模式: ​​ 尽可能少地匹配字符 ​​，满足最小匹配条件就停止
5.1.1.2 示例
  • 隐藏手机号中四位
  • 提取网页链接
  • 提取 JSON 中的数值
  • r'' 内的内容是匹配规则
  • : "(.*?)"
    • : 正常匹配
    • "" 也是正常匹配
    • ()捕获分组
    • (.*?) 分组内非贪婪匹配

匹配步骤：

  1. 找到第一个  ": "→ 位置在  "name": "Alice"中

  2. 开始捕获  .*?：

    • 遇到  A→ 匹配
    • 遇到  l→ 匹配
    • 遇到  i→ 匹配
    • 遇到  c→ 匹配
    • 遇到  e→ 匹配
    • 遇到  "→ 停止（非贪婪模式）

  3. 返回捕获内容：Alice

  4. 继续查找下一个  ": "→ 位置在  "city": "Beijing"中

  5. 同样方式捕获  Beijing
