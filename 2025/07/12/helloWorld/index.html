当你使用 wsl --unregister <DistributionName> 命令时，原本在 WSL（Windows Subsystem for Linux）中的文件不会被删除。这个命令的作用是注销（unregister）一个已安装的 Linux 发行版，而不是删除文件。

  • WSL 的文件存储方式：WSL 中的文件实际上是存储在 Windows 文件系统中的一个虚拟硬盘（通常是 .vhdx 文件）。注销发行版时，WSL 只是移除了对这个虚拟硬盘的挂载和管理，但不会删除虚拟硬盘本身。
  • 文件仍然存在：即使你注销了某个发行版，它的文件仍然保留在 Windows 系统的某个位置（通常是 C:\Users\<YourWindowsUsername>\AppData\Local\Packages\<DistributionPackageName>）

默认进入家目录

/mnt/d/software/WSL  是因为 WSL 会自动将 Windows 的磁盘挂载到 Linux 系统的  /mnt/  目录下。具体来说：

  1. /mnt/d/  对应的是 Windows 的  D 盘。
  2. /mnt/d/software/WSL  是 Windows 系统中  D:\software\WSL  目录在 WSL 中的路径。
