1 Miniconda

Miniconda 是 Anaconda 的精简版，仅包含 Python、Conda 包管理器和基础依赖（约 70MB），避免预装大量科学计算包占用空间。

核心价值：

  • ​​ 环境隔离 ​​：为每个项目创建独立环境（如python=3.8），避免库版本冲突
  • ​​ 依赖管理 ​​：自动解决 CUDA、cuDNN 等深度学习框架的复杂依赖（尤其 GPU 环境）
  • ​​ 跨平台兼容 ​​：同一套命令管理 Windows/Linux/macOS 环境。
维度 Miniconda Docker
​​ 隔离级别 ​​ 应用级（Python 环境+依赖库） 系统级（进程/文件系统/网络隔离）
​​ 资源占用 ​​ 低（仅环境目录） 高（需运行容器引擎）
​​ 适用场景 ​​ 多 Python 项目隔离 全栈环境一致性（含 OS 依赖）
​​ 结合使用 ​​ 在 Docker 容器内安装 Miniconda 用 Docker 封装系统，Conda 管理 Python 包
