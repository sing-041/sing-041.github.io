1 Claude Code 是什么

Claude Code 是一个 AI 助手，它住在你电脑的终端里。你用自然语言跟它说话，它帮你干活——写文档、写代码、分析文件、搜索内容，什么都行。

1.1 Claude Code 和 LLM

LLM （Large Language Model）就是我们常说的大模型。API 是这个大模型的使用权。

Claude Code 是工具，LLM 是大脑。以下举一个例子来说明：

这里我们提供两个 LLM：一个是马斯克的大脑，一个是我的大脑。
我们提供两个大脑的容器：一个是蚂蚁，一个是人类。

如果蚂蚁拥有马斯克的大脑，由于它不会使用工具，以及自身活动性等等条件不好。所以它能做到的只是找到距离事物的最短路径。这说明一个好的模型没有一个好的工具，相当浪费。

那如果我和马斯克都想要解决自身移动速度慢的问题，我的大脑能指挥身体做的是打工挣钱，买汽车。马斯克的大脑指挥身体做的是拉融资找团队造火箭。

那么 Claude Code 是主流认为的最强工具之一（强于 OpenClaw） ，GLM-5 是由清华团队开发的大模型，去年在香港上市号称中国模型第一股，也是中国最强模型（但是小米也说它是最强模型，DS 也说它是最强模型）。

2.7 注意

这里有个小建议，在使用 Claude 的时候，我们一定要先进入到我们的项目文件夹下，在右键终端，这样路径会是该项目文件夹。既方便 Claude 工作，也方便我们自己管理。

  • Claude 会优先读取当前文件夹下的内容
  • 除非是特殊情况，否则一般不会读取当前文件夹外的内容
