Ubuntu 开发环境配置

前置阅读：[[Linux 入门实战]]（理解 Linux 基础概念）

这篇是 apt 的实战：装完 Ubuntu 后，作为开发者需要配置什么。

1 换国内软件源

1.1 为什么要换

Ubuntu 默认软件源在国外，国内下载速度慢。换成阿里/清华源后，apt install 会快很多。

1.2 操作步骤

2 系统基础工具

以下工具用 apt install 一次性装完：

  • -y：自动确认安装，不用中途按 y。
软件 作用
build-essential 编译工具链（gcc、g++、make），很多工具编译安装依赖它
git 版本控制，开发者必装
wget、curl 命令行下载工具，安装脚本常用
vim 终端编辑器，修改配置文件用
htop 进程查看器，比 top 更直观
tree 目录树查看，快速了解项目结构
zip、unzip 压缩解压工具

3 开发环境：版本管理工具

3.1 为什么需要版本管理工具

直接用 apt install nodejs 或 apt install python3：

  • 装的版本可能很旧（Ubuntu 官方源更新慢）
  • 无法切换版本（不同项目可能需要不同版本）
  • 卸载/升级麻烦

版本管理工具解决这些问题：

  • 安装任意版本
  • 多版本共存、随时切换
  • 避免项目间版本冲突

3.2 常用工具一览

工具 管理什么 常用命令
nvm Node.js 版本 nvm install 20、nvm use 20、nvm ls
pyenv Python 版本 pyenv install 3.10、pyenv global 3.10、pyenv versions
poetry Python 项目依赖 poetry init、poetry add 包名、poetry install

3.3 安装方式

这些工具通过官方脚本安装，具体命令请查阅官方文档：

  • nvm：[[nvm 环境配置]]
  • pyenv：[[pyenv 环境配置]]
  • poetry：[[poetry 环境配置]]

3.4 注意事项

  • 安装后需重启终端：或执行 source ~/.bashrc（或对应的配置文件），否则命令不生效
  • pyenv 依赖编译工具：先装好第 2 节的 build-essential，否则 Python 编译安装会失败
